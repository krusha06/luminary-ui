Why Luminary

Built for real
production work.

Not another pretty prototype. Every component is ready to ship.

⚡
Zero Dependencies
Pure CSS animations and vanilla JS interactions. No runtime bloat, no version conflicts.
♿
Accessible First
WCAG 2.1 AA compliant. Proper ARIA roles, keyboard navigation, and focus management built in.
🎨
Themeable
Token-based design system. Override any CSS variable to match your brand in seconds.
📦
Framework Agnostic
Works with React, Vue, Svelte, Angular, or just HTML. Bring your own toolchain.
🌙
Dark by Default
Designed in dark mode first. Light mode support via a single class swap on the root element.
✨
Motion Design
Purposeful animations with spring physics. Every interaction feels alive and intentional.

today.
